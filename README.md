## 🚀 Featured AI Projects

*Project roadmap — implementation status and results will be added as each project progresses.*

### 1. Multimodal RAG System
**Stack:** Python · FastAPI · LLMs · Embeddings · Vector Search · OCR/Vision

Build a RAG application that answers questions from PDFs, text, tables, and images, with source references for traceable responses.

- **Core features:** Document ingestion, multimodal retrieval, optional reranking, and source-grounded answers.
- **Evaluation:** Measure retrieval quality, answer faithfulness, citation accuracy, and latency.

### 2. Real-Time UPI Fraud Detection
**Stack:** Python · Apache Kafka · Machine Learning · FastAPI

Develop a streaming pipeline that scores transaction events and flags potentially fraudulent activity using simulated or authorized data.

- **Core features:** Kafka event processing, model-based risk scoring, and an API for reviewing alerts.
- **Evaluation:** Track precision, recall, PR-AUC, false positives, and processing latency.

### 3. LLM Fine-Tuning with LoRA / QLoRA
**Stack:** Python · PyTorch · Hugging Face Transformers · PEFT

Experiment with parameter-efficient fine-tuning to adapt a pretrained language model to a focused task.

- **Core features:** Dataset preparation, baseline testing, adapter fine-tuning, and reproducible experiments.
- **Evaluation:** Compare the base and fine-tuned models on held-out data for quality, latency, and memory use.
