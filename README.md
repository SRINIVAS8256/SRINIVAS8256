## 🚀 Featured projects

### 1. GenAI-Powered Resume Screener & Job-Fit Analyzer
**Python · FastAPI · LLM APIs · Pandas · Docker**

- Parses PDF/DOCX resumes and extracts structured candidate information.
- Exposes upload, parsing, and AI-based job-match scoring through REST endpoints.
- Produces explainable, section-wise feedback such as skills gaps and experience fit.
- Containerizes the backend with Docker.

### 2. Movie Recommendation System
**Python · Pandas · NumPy · scikit-learn · TF-IDF · Cosine Similarity**

- Builds a content-based recommender using movie metadata.
- Cleans and engineers features from a dataset of 5,000+ movies.
- Uses text vectorization and cosine similarity to retrieve similar movies.

### 3. End-to-End ML Pipeline with MLOps Deployment
**Python · scikit-learn · FastAPI · Docker · GitHub Actions**

- Implements data ingestion, preprocessing, model training, and evaluation.
- Serves predictions through a FastAPI inference endpoint.
- Uses Docker for portable deployment and a GitHub Actions CI workflow for automated testing.
